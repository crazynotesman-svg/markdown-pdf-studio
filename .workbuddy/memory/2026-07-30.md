## 构建：极简 Markdown 转 PDF 工具站（Astro + Cloudflare Pages）

- 技术栈：Astro 4.16（static 输出），marked + DOMPurify 客户端渲染，html2pdf.js（esm.sh 动态导入）做一键下载，浏览器原生打印做「另存为 PDF」。
- 结构：
  - `src/components/MarkdownPdfTool.astro`：双栏工具（左 textarea / 右 A4 预览），工具栏含示例/清空/加粗/打印/下载。
  - `src/layouts/BaseLayout.astro`：统一注入 canonical、OG、Twitter Card、JSON-LD（WebSite / BlogPosting / SoftwareApplication）。
  - `src/content/blog/*.md`：3 篇带 SEO keywords 的示例博文（Markdown转PDF / 博客SEO / Cloudflare部署）。
  - `src/pages/sitemap.xml.ts` 与 `rss.xml.ts`：自建站点地图与 RSS（**未用 @astrojs/sitemap**，因其依赖 `astro:routes:resolved` 钩子与 Astro 4.16 不兼容，会报 `_routes.reduce` 错误）。
  - `src/site.config.ts`：集中配置 url / github，部署前必改。
- 构建验证通过：`npm run build` 成功，dist/ 含首页、博客、about、sitemap.xml、rss.xml、robots.txt。
