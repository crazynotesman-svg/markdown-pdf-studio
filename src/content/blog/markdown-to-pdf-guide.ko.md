# Markdown을 PDF로: 완전 가이드

Markdown은 미니멀한 일반 텍스트 문법으로 사랑받고, PDF는 크로스 플랫폼에 고정 레이아웃인 「최종 결과물」입니다. 둘을 결합하는 것은 작성자, 개발자, 운영자의 일상적인 요구입니다. 이 글은 **Markdown을 PDF로** 바꾸는 몇 가지 방법과 트레이드오프를 체계적으로 설명합니다.

## 왜 Markdown을 PDF로 변환하나요

- **글쓰기에 집중**: Markdown은 형식에 신경 쓰지 않고 내용에만 집중하게 해줍니다.
- **안정적인 전달**: PDF는 어떤 기기에서도 레이아웃이 동일해 계약서, 이력서, 문서에 적합합니다.
- **버전 관리 가능**: 소스 파일이 일반 텍스트라 Git에 자연스럽게 잘 맞습니다.

## 세 가지 주요 방식

### 1. 브라우저 인쇄 (가장 정확)

Markdown을 HTML로 렌더링한 뒤 브라우저의 「인쇄 → PDF로 저장」을 사용합니다. 장점: 스타일 100% 일치, 종속성 없음, 무료. 이 도구의 「인쇄 / PDF로 저장」 버튼이 바로 이 원리입니다.

### 2. 프론트엔드 라이브러리로 한 번에 내보내기 (가장 편리)

`html2pdf.js`(`html2canvas` + `jsPDF` 래핑)를 사용해 페이지를 PDF 파일로 바로 변환합니다. 장점은 클릭 한 번으로 다운로드된다는 점이지만, 복잡한 CSS(페이지 나누기, 배경 등)는 약간 다를 수 있습니다.

### 3. 명령줄 (일괄 작업에 적합)

`pandoc`, `mdpdf`, `weasyprint` 등. CI에서 일괄 생성에 좋지만 환경 구성이 필요합니다.

## 레이아웃 모범 사례

1. `@page { size: A4; margin: 16mm; }`로 인쇄 여백을 제어합니다.
2. 코드 블록에는 고정 폭 글꼴을 쓰고 색상을 유지해 가독성을 높입니다.
3. 긴 표에는 `pagebreak` 규칙을 사용해 잘림을 방지합니다.
4. 너비를 픽셀로 고정하지 말고 PDF가 페이지에 맞춰지게 합니다.

## 요약

**완전한 일치**를 원하면 브라우저 인쇄를, **한 번에 다운로드**를 원하면 프론트엔드 라이브러리를 쓰세요. 이 도구는 둘 다 제공합니다——왼쪽에 Markdown을 쓰면 오른쪽에 A4 레이아웃이 실시간으로 미리 보이고, 그대로 내보낼 수 있습니다.
