# Бесплатный деплой статического сайта на Cloudflare Pages

Cloudflare Pages предлагает бесплатный хостинг статических сайтов плюс глобальный CDN и глубоко интегрируется с GitHub: **пуш — и деплой**. Вот полный процесс.

## Предварительные условия

- Репозиторий GitHub (исходный код сайта)
- Аккаунт Cloudflare (бесплатного тарифа достаточно)
- Команда сборки и каталог вывода (например, Astro: `npm run build` → `dist`)

## Шаги деплоя

### 1. Отправьте код в GitHub

```bash
git init
git add -A
git commit -m "init"
git remote add origin https://github.com/crazynotesman-svg/markdown-pdf-studio.git
git push -u origin main
```

### 2. Подключите репозиторий в Cloudflare Pages

1. Панель Cloudflare → **Workers & Pages** → **Create** → **Pages**.
2. Выберите **Connect to Git**, авторизуйтесь и выберите свой репозиторий.
3. Задайте сборку:
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
4. Нажмите **Save and Deploy**.

### 3. Автодеплой при каждом обновлении

После этого любой `git push` заставляет Cloudflare автоматически забирать, собирать и публиковать код, а также сохранять ссылку-превью для каждого деплоя.

## Настройка собственного домена (необязательно)

В разделе **Custom domains** проекта Pages добавьте свой домен и направьте его DNS CNAME на Pages согласно подсказке. Cloudflare автоматически выпустит SSL-сертификат, поэтому HTTPS работает из коробки.

## Частые проблемы

- **Неверные абсолютные ссылки**: не забудьте указать в конфиге `site` как ваш настоящий домен, иначе sitemap/canonical будут содержать плейсхолдеры.
- **Тайм-аут сборки**: бесплатного тарифа хватает для небольших сайтов; сократите зависимости, если их слишком много.
- **Переменные окружения**: чистым статическим сайтам они обычно не нужны, но если нужны — задайте их в **Settings → Environment variables** Pages.

## Итог

GitHub управляет контентом, Cloudflare Pages — доставкой: эта связка бесплатна, глобально ускорена и автоматически деплоится, что идеально для личных проектов и технических блогов.
