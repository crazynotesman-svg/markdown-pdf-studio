# Markdown в PDF: полное руководство

Markdown ценят за минималистичный синтаксис обычного текста, а PDF — это кроссплатформенный «итоговый документ» с фиксированной вёрсткой. Сочетать их — повседневная задача для авторов, разработчиков и команд. В этой статье системно разбираются варианты и компромиссы **Markdown в PDF**.

## Зачем конвертировать Markdown в PDF

- **Сосредоточенность на тексте**: Markdown позволяет думать только о содержании, а не о форматировании.
- **Стабильная доставка**: PDF сохраняет одинаковую вёрстку на любом устройстве — идеально для договоров, резюме и документов.
- **Версионность**: исходники — это обычный текст, что естественно подходит для Git.

## Три основных подхода

### 1. Печать в браузере (точнее всего)

Преобразуйте Markdown в HTML и используйте «Печать → Сохранить как PDF» в браузере. Плюсы: стиль на 100% совпадает, без зависимостей, бесплатно. Именно этот принцип лежит в основе кнопки «Печать / Сохранить как PDF» в этом инструменте.

### 2. Экспорт в один клик через фронтенд-библиотеку (удобнее всего)

Используйте `html2pdf.js` (оборачивает `html2canvas` + `jsPDF`), чтобы превратить страницу напрямую в PDF-файл. Плюс — загрузка одним кликом, но сложный CSS (нумерация страниц, фоны) может слегка отличаться.

### 3. Командная строка (лучше для пакетов)

Например, `pandoc`, `mdpdf`, `weasyprint`. Подходят для пакетной генерации в CI, но требуют настройки окружения.

## Лучшие практики вёрстки

1. Используйте `@page { size: A4; margin: 16mm; }` для управления полями печати.
2. Для блоков кода используйте моноширинный шрифт и сохраняйте подсветку для читаемости.
3. Для длинных таблиц используйте правила `pagebreak`, чтобы избежать обрывов.
4. Избегайте жёсткой ширины в пикселях; пусть PDF подстраивается под страницу.

## Итог

Для **абсолютного совпадения** используйте печать в браузере; для **загрузки в один клик** — фронтенд-библиотеку. Этот инструмент даёт оба варианта: пишите Markdown слева, справа видьте живое превью вёрстки A4 и экспортируйте.
